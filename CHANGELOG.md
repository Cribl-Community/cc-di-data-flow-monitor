# Changelog

All notable changes to Data Flow Monitor for Cribl are documented here.

## 1.0.0

First release.

- **Overview**: a fleet-level dashboard with KPIs, an Alert Feed, a Volume Matrix, Daily Ingest against your license entitlement, Worker Inventory, and Worker Comparison.
- **Signal Path**: a live, end-to-end wiring diagram from Source through Routes, Pipelines, and Functions to Destination, with real health coloring, hover highlighting, per-node detail panels, and Live Capture at all four checkpoints.
- **Flow Explorer**: the same flow data as a sortable, searchable table, with an inline expandable view of each flow's full chain.
- Support for both Cribl Stream and Cribl Edge, including a merged view across every Worker Group or Edge Fleet.
- Dark and light themes.
